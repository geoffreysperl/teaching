# About the Site

## Website

This website is protected by copyright. The code sits in a my private repository on GitHub, and the site is published with <a href="https://jekyllrb.com/">Jekyll</a> and self-hosted (currently on Netlify). The git repository is private because it is using the paid theme "Akio" from <a href="https://index.jekyllthemes.io/">Jekyll Themes</a> (crafted & designed by <a href="https://jekyllthemes.io/developers/artem-sheludko">Artem Sheludko</a>). Thus, I cannot open this up to Creative Commons (but do check out the themes on Jekyll Themes!).

## Privacy

I don't track visitors to the site. No Google Analytics, no tracking pixels, no tracking links to Facebook or Instagram or a certain someone's boutique social network (once known as Twitter). This is just a website.
